## 🛠️ Featured Engineering Competencies & Case Studies

### 1. Budgetary Proposal for Equipment in a Steel Plant
- Formulated comprehensive CAPEX budgetary proposals and equipment planning for a greenfield steel manufacturing facility.
- 2D and 3D equipment layouts in AutoCAD, material handling flow, 25T overhead crane hook clearance envelopes, and civil foundation load interfaces.
- Evaluation of supplier technical quotations and equipment comparison matrices.

### 2. Air Cargo Ground Support Equipment (GSE)
- **Powered Roller Deck & Lazy Dolly Castor Deck System**:
  - Handled 7,000 kg Unit Load Devices (ULDs e.g., LD3, LD7, PMC pallets).
  - Motorized chain drives, bidirectional pallet stops, and an omnidirectional ball castor matrix on a 55mm pitch conforming to IATA / AHM airport standards.

### 3. Automated Special Purpose Machinery (SPM)
- **Automated T-Spacer Precision Cutting Machine**:
  - Linear servo ball screws, dual pneumatic clamping jaws lined with urethane, high-speed carbide circular saw blade, and 1.8 second cycle time with ±0.05 mm cut tolerance.
- **Industrial Strip Flattening Machine**:
  - 17-roll precision leveling cassette with induction-hardened chrome-plated 42CrMo4 alloy steel rolls and 80 kN hydraulic downforce to eliminate coil set across 1,200 mm wide high-tensile steel coils.

### 4. Load Analysis & Physical Proof Testing
- Structural validation combining digital Finite Element Analysis (Von Mises stress, strain, deflection) in SolidWorks Simulation / ANSYS with real-life physical proof loading using calibrated hydraulic rams and strain gauges (`FoS > 2.85` certified).

### 5. AutoCAD Documentation & Site Commissioning
- Complete 2D manufacturing packages conforming to **ASME Y14.5M GD&T**, Bills of Materials (BOM), weldment callouts (AWS D1.1), and First Article Inspection (FAI) reports.
- Real-time on-site engineering redlines during plant commissioning to reconcile foundation deviations with mechanical clearances.

### 6. Photorealistic KeyShot 3D Renderings
- Studio HDRI ray-traced materials, exploded assembly views, and animations for high-stakes executive client proposals.

## ⚡ How to Run Locally

### Option 1: Native Windows PowerShell Server
```powershell
powershell -ExecutionPolicy Bypass -File .\serve.ps1
```
Open **`http://localhost:8080`** in your browser.

### Option 2: Any Static Web Server
```bash
# Python
python -m http.server 8080

# Node / npx
npx serve .
```

## 🌐 Deploying to GitHub Pages (Free Live Hosting)

1. Create a new repository on [GitHub](https://github.com/new) named `portfolio` (or `karampudi-acharya-pranav.github.io`).
2. Push or upload these files to the `main` branch.
3. In your GitHub repository:
   - Go to **Settings** > **Pages**.
   - Under **Build and deployment** > **Source**, select **Deploy from a branch**.
   - Select **main** branch and **/ (root)** folder.
   - Click **Save**.
4. Within 60 seconds, your portfolio will be publicly live at:
   `https://<your-username>.github.io/portfolio/`
